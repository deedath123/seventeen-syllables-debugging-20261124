Entry for the [Seventeen Syllables of Debugging](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605) bounty on make.fun.

A single haiku about debugging, in strict 5-7-5 syllables:

> Breakpoint set at dawn
> the log shows nothing at all
> the bug wore my name

## Run

```sh
python3 main.py
```

Writes exactly those three lines (with a single trailing newline) to `/output/entry.txt`. Stdlib only, no dependencies.
